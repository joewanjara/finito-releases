# Finito downloads

Download the latest macOS test build from [Releases](https://github.com/joewanjara/finito-releases/releases/latest).

Open the DMG and drag Finito to Applications. Finito 0.9.3 and later can check for updates through **Finito → Check for Updates…** or **Settings → Updates**. Earlier versions need this one-time manual installation.

This repository contains application downloads, release notes and the signed Sparkle update feed. The application source is maintained separately in a private repository. No source-code licence is granted by distributing these test builds.

Apple Silicon; macOS 14 or later. These builds are locally signed and not Apple-notarized; macOS may require approval to open them. Update archives and the feed are separately signed for verification by Finito. Back up important artwork before testing.
