# Finito 0.9.4

- Added Standard, 2K and 4K sizing options for Transform presets; 2K uses a 2048-pixel longest side.
- Added a remembered export DPI option, defaulting to 300 DPI, with remembered Transform dimensions, appearance and output format.
- Transform settings remain disabled until Resize Artwork is enabled; original files remain untouched.
- Artwork Review selected from the floating assistant now opens Finito and starts the review immediately.
